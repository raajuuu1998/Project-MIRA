Why Cross-Cancer Generalization Matters in Computational Pathology

A pathology model is most useful when the signal it learns survives changes in cancer type, cohort, institution, and acquisition conditions.

Good performance within one cancer is not the same as transfer

Computational pathology models are often developed and evaluated within a single disease cohort. This is a useful starting point, but it does not answer a more difficult question: does the learned representation still contain the right information when the model is moved to a morphologically different cancer?

A model can achieve strong internal discrimination while relying partly on features that are specific to the source organ, cohort, scanner, staining process, or patient population. These features may be predictive in the development dataset but become unreliable when the deployment setting changes.

Cancer-type shift is more than a scanner shift

Cross-site generalization usually asks whether a model survives technical differences such as staining, scanners, laboratories, or acquisition pipelines. Cross-cancer generalization adds a biological shift. Tissue architecture, cellular composition, stromal organization, and tumor morphology can all change substantially between organs.

This means that a transferable pathology representation must preserve disease-relevant information without depending too strongly on organ-specific appearance. The problem is therefore not only to remove technical variation, but to identify which biological signals remain useful across distinct tissue contexts.

Molecular biomarkers create a useful test case

Biomarkers such as microsatellite instability and tumor mutational burden provide an interesting setting for studying transfer. Their molecular mechanisms are not identical, and their histological manifestations can vary across cancers, yet both can be associated with recurring tumor–immune patterns.

This creates a useful scientific question: can a model use recurring biological structure, rather than only source-specific morphology, to improve prediction in an unseen cancer? Evaluating that question requires strict separation between the source data used for development and the target cancer used for testing.

What should be measured

A convincing cross-cancer study should report more than one internal validation score. External cohorts, multiple target cancers, cross-site evaluation, confidence intervals, reciprocal transfer directions, calibration, and component ablations can help distinguish a genuinely transferable signal from a source-specific result.

Negative transfer is also informative. If a method improves one source–target pair but degrades another, that asymmetry can reveal that transfer depends on the biological relationship between cancers rather than on a universal invariant representation.

The goal is not to make every cancer look the same

Cross-cancer generalization should not be interpreted as forcing all tissue types into a single cancer-invariant representation. Organ-specific morphology contains real biological information and should not simply be removed.

A more useful goal is to learn representations in which clinically relevant signals remain accessible despite changes in tissue context. That shifts the emphasis from maximizing performance on one benchmark to understanding which histopathological features are biologically meaningful, transferable, and robust.
